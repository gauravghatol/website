# 📝 Rich Text Editing Quick Reference

## 🚀 Quick Start

1. Go to `/admin/departments`
2. Click on any department
3. Click on any paragraph text
4. Use the toolbar that appears
5. Click ✅ Save to apply formatting

## 🎨 Toolbar Features

### Row 1: Text Style

```
[Font Family ▼] [Font Size ▼] [Heading ▼]
```

**Available Fonts:**

- Arial (Modern)
- Comic Sans (Casual)
- Courier New (Technical)
- Georgia (Classic)
- Helvetica (Professional)
- Lucida (Elegant)
- Times New Roman (Traditional)
- Verdana (Readable)

**Font Sizes:**
10px, 12px, 14px, 16px, 18px, 20px, 24px, 28px, 32px, 36px, 48px, 60px, 72px

### Row 2: Formatting

```
[B] [I] [U] [S]
```

- **B** = Bold
- **I** = Italic
- **U** = Underline
- **S** = Strikethrough

### Row 3: Colors

```
[A▼] [Background▼]
```

- Text color picker
- Background color picker

### Row 4: Alignment

```
[≡] [≡] [≡] [≡]
```

- Align left
- Align center
- Align right
- Justify

### Row 5: Lists & Structure

```
[1.] [•] [⫷] [⫸]
```

- Ordered list (1, 2, 3...)
- Bullet list
- Decrease indent
- Increase indent

### Row 6: Special

```
["] [</>] [🔗] [Clear]
```

- Blockquote
- Code block
- Insert link
- Clear formatting

## 💡 Pro Tips

### Best Font Sizes for Different Content

```
Body Text:      14-18px
Subheadings:    20-24px
Main Headings:  28-36px
Banner Text:    48-72px
```

### Recommended Font Combinations

```
Professional:   Helvetica (headings) + Georgia (body)
Academic:       Times New Roman (headings) + Arial (body)
Modern:         Verdana (headings) + Arial (body)
Technical:      Courier New (code) + Arial (text)
```

### Color Best Practices

- **Primary:** Navy Blue (#003366) - SSGMCE Blue
- **Accent:** Orange (#FF6B35) - SSGMCE Orange
- **Text:** Dark Gray (#333333)
- **Background:** Light Gray (#F5F5F5) for highlights

## ⚡ Keyboard Shortcuts

```
Ctrl + B    = Bold
Ctrl + I    = Italic
Ctrl + U    = Underline
Ctrl + K    = Insert link
Ctrl + Z    = Undo
Ctrl + Y    = Redo
```

## ✅ Common Tasks

### Make a heading stand out

1. Select the text
2. Choose "Georgia" font
3. Select "24px" size
4. Click Bold [B]
5. Change color to SSGMCE Blue
6. Click center align

### Format HOD message

1. Set font to "Georgia"
2. Set size to "16px"
3. Click justify alignment
4. Make signature italic
5. Center-align signature

### Create an important notice

1. Select the text
2. Make it Bold
3. Set size to "18px" or "20px"
4. Change text color to red or orange
5. Add yellow background color

### Format a list properly

1. Select items
2. Click bullet list [•]
3. Set font to "Arial"
4. Set size to "16px"
5. Leave alignment at left

## 🔧 Troubleshooting

**Q: Editor not appearing?**
A: Ensure you're on a multiline text field (paragraphs, descriptions, etc.)

**Q: Changes not saving?**
A: Click ✅ Save in editor, then "Save All Changes" in toolbar

**Q: Formatting looks different after save?**
A: Clear browser cache and reload the page

**Q: Can't select font?**
A: Click inside the editor first, then use toolbar

**Q: Want to remove all formatting?**
A: Select text and click "Clear" button (🗑️)
